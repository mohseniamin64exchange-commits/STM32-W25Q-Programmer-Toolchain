# STM32 + W25Q Asset Toolchain

مستند مادر پروژه ابزارهای آماده‌سازی، بسته‌بندی و پروگرام منابع برای سامانه‌های مبتنی بر STM32 و حافظه‌های خارجی سری W25Q.

## هدف پروژه

ساخت زنجیره‌ای است که فایل‌های معمولی مانند تصویر، صدا و فونت را به قالب مناسب سیستم نهفته تبدیل کند، آن‌ها را در یک بسته منظم برای W25Q قرار دهد، کتابخانه و شناسه‌های لازم برای STM32 را بسازد و در نهایت Firmware و منابع را با فرایندی ساده پروگرام کند.

هدف تجربه نهایی این است که برنامه‌نویس با آدرس‌های فیزیکی حافظه درگیر نشود و از API سطح بالا استفاده کند:

```c
Asset_DrawImage(IMG_STARTUP, 0, 0);
Asset_PlayAudio(SOUND_WARNING);
Asset_DrawText(FONT_VAZIR_24, "هشدار", 100, 50);
```

## محدوده فعلی

- میکروکنترلر مرجع اولیه: `STM32F103VET6`
- حافظه خارجی مرجع اولیه: `W25Q16` با ظرفیت ۲ مگابایت
- ارتباط حافظه: SPI
- پروگرام میکروکنترلر: ST-Link / SWD
- پروگرام W25Q: از طریق STM32 واسط یا CH341A

این انتخاب‌ها نقطه شروع‌اند و معماری باید بعداً برای STM32ها و W25Qهای دیگر قابل توسعه باشد.

## محصولات پروژه

### ۱. Media Converter

نرم‌افزار تبدیل اولیه منابع:

- `PNG/JPG/BMP` به تصویر `RGB565`
- `MP3/WAV/میکروفون` به `PCM` یا `IMA-ADPCM`
- `TTF/OTF` به Bitmap Font به‌همراه جدول حروف
- پیش‌نمایش، پخش آزمایشی، تغییر اندازه و نمایش حجم خروجی
- ذخیره هر منبع تبدیل‌شده به‌صورت مستقل

> RGB565 فقط برای تصویر است. صوت به PCM یا ADPCM تبدیل می‌شود.

### ۲. Asset Builder

نرم‌افزار ساخت پروژه حافظه:

- ورود تصاویر، صداها، فونت‌ها، آیکون‌ها، انیمیشن‌ها و داده‌های دیگر
- نام‌گذاری و اختصاص شناسه ثابت
- دسته‌بندی، چیدمان و تعیین آدرس در W25Q
- کنترل ظرفیت و جلوگیری از هم‌پوشانی
- ایجاد جدول منابع و CRC32
- ساخت `assets.bin`
- تولید `asset_ids.h`
- تولید کتابخانه خواندن و استفاده از منابع در STM32
- دریافت `firmware.hex` و ساخت بسته تحویل پروژه

## خروجی‌های اصلی

```text
firmware.hex   -> Flash داخلی STM32
assets.bin     -> حافظه خارجی W25Q
asset_ids.h    -> شناسه‌های مشترک میان Builder و Firmware
library/       -> درایورها و API سمت STM32
project.w25pack -> بسته واحد تحویل و پروگرام
```

`firmware.hex` و `assets.bin` متعلق به دو تراشه و دو فضای آدرس مستقل هستند؛ داخل بسته نهایی کنار هم قرار می‌گیرند اما از نظر فنی یکی نمی‌شوند.

## روش‌های پروگرام W25Q

### STM32 به‌عنوان واسط

```text
PC <-> USB/UART <-> STM32 <-> SPI <-> W25Q
```

STM32 با Firmware واسط موقت یا Bootloader دائمی، بسته منابع را دریافت و W25Q را پاک، پروگرام و Verify می‌کند.

### پروگرام مستقیم با CH341A

```text
PC <-> USB <-> CH341A <-> SPI <-> W25Q
```

CH341A مستقیماً W25Q را پروگرام می‌کند. در این حالت STM32 باید در Reset یا وضعیت بدون مزاحمت روی خطوط SPI باشد.

### راهبرد پیشنهادی

- STM32 واسط: به‌روزرسانی عادی و آسان منابع
- CH341A: تولید اولیه، تعمیر و بازیابی
- ST-Link: پروگرام و بازیابی Firmware میکروکنترلر

## زمان هدف

- Firmware: حدود ۵ تا ۱۰ ثانیه
- پروگرام کامل W25Q16: حدود ۱۰ تا ۲۰ ثانیه در پیاده‌سازی بهینه
- کل فرایند هدف: حدود ۲۰ تا ۳۰ ثانیه
- به‌روزرسانی تفاضلی منابع تغییرکرده: چند ثانیه

این اعداد تخمینی‌اند و باید روی برد واقعی با مدل دقیق فلش، سرعت SPI و مسیر USB/UART اندازه‌گیری شوند.
